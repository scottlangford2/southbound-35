# Eanes ISD & Recapture — replication

Build script for the Southbound 35 post **"Eanes ISD and Robin Hood: How Recapture Actually Works"** (June 2026).

## Run

```bash
pip install -r requirements.txt
python build_figures.py
```

Outputs five PNGs to `images/eanes/` in the website repo.

## Sources

- Texas Education Agency, *Recapture* annual summaries
- TEA, *School District Funding* (SDF) reports
- Eanes ISD adopted budgets and tax rate filings
- HB 3 (86th Legislature, 2019)

Values are transcribed from published TEA tables and cited in each
chart's source line.
