# I-35 Austin–San Antonio Corridor — replication

Build script for the Southbound 35 post **"Eighty Miles: A Short History of the I-35 Corridor Between Austin and San Antonio"** (June 2026).

## Run

```bash
pip install -r requirements.txt
python build_figures.py
```

Outputs five PNGs to `images/i35/` in the website repo.

## Sources

- U.S. Census Bureau, Decennial Census 1950–2020, ACS 2023 1-year
- Texas Demographic Center, county population estimates
- TxDOT Statewide Traffic Analysis & Reporting System (STARS) — AADT counts
- U.S. Bureau of Economic Analysis, regional GDP by county
